에우리디케 2D 홀로그램 — v1 동굴 시나리오 테스트

열 씬
Assets/OrpheusVR/Scenes/Orpheus_Underworld_HologramTest.unity
기존 v1 및 원형 v2 동굴 씬은 별도로 유지됩니다.

시작
Unity 6000.3.26f1에서 위 씬을 열고 Play를 누릅니다.
Game 탭이 없으면 Window > General > Game을 엽니다.
화면 아래쪽의 테스트 버튼으로 구간과 결말을 바로 선택할 수 있습니다.
Tab: 긴 도입 설명을 건너뛰고 에우리디케 등장.
E / Enter: 대사 자막이 끝난 뒤 손 잡고 출발.
컨트롤러 A도 손잡기 버튼으로 사용할 수 있습니다. 실제 손 추적/그랩은 아직 아닙니다.
F: 자동 시나리오 테스트. 도입을 건너뛰고 이동·리라·공명·기다림 결말을 진행합니다.
자동 모드의 카메라 경로 보정은 상실 판정에서 제외합니다. 수동 모드에서는 시선 규칙을 적용합니다.
WASD 이동 / 우클릭 시점 회전 / E 가까운 소품 상호작용.
R: 처음부터 다시.

바로 테스트
1: 도입 다시 보기
2: 동행 테스트 — 에우리디케가 약 2.5m 뒤에서 실제 이동 궤적을 따라옵니다.
3: 넘어짐 — 침수 트리거와 앉은 PNG 전환, 다친 위치에서 멈춤.
4: 선택 지점
5: 기다리기 — 선택 지점에서 4초 기다린 뒤 회복, 서 있는 PNG로 복귀.
6: 홀로 나가기 — 에우리디케는 지하세계에 남고 플레이어만 나갑니다.
7: 상실 바로 테스트 — 디졸브로 사라짐.
8: 함께 지하세계에 남는 결말 바로 테스트.
시선 테스트: 동행 중 통로 진행 방향에서 70도 이상 돌아보면 경고 자막,
120도 이상을 2초 유지하면 상실. 2초 전에 돌아오면 누적 시간이 취소됩니다.
마지막 선택 지점에서 뒤돌아보면 함께 지하세계에 남는 결말입니다.
기다림 후 플레이어와 에우리디케가 모두 출구 밖에 도달하면 재회 자막이 나오고
뒤돌아보기 제한이 해제됩니다.

이미지 / 머티리얼
서 있는 자세와 넘어진 자세의 실제 알파 투명 PNG 2장을 사용합니다.
사용자 피드백에 따라 청록색 테두리를 약하게 편집한 *_softglow.png가 최종 적용본입니다.
원본 PNG는 비교용으로 보존했습니다. 얼굴·피부·중앙 드레스의 가독성을 유지했습니다.
머티리얼: Hologram/Materials/Eurydice_Hologram.mat
Cyan Glow Opacity = 0.12: 청록색 광채 픽셀의 알파만 낮춥니다. 0이면 더 투명합니다.
Opacity = 0.7: 캐릭터 전체의 기본 영혼 투명도입니다.
Dissolve = 0이면 보임, 1이면 사라짐. 등장/상실/포즈 전환은 코드가 제어합니다.
Shader Graph 파일 대신 같은 노이즈→임계값→알파 방식을 구현한 URP Unlit 셰이더를 사용합니다.
빌보드는 수직축으로만 회전하며 플레이어를 향합니다. 이동은 PNG 평면의 위치 이동이며,
3D 모델링·리깅·자연스러운 보행 애니메이션은 포함하지 않습니다.

TTS 상태
사용자 요청으로 TTS 제작 및 적용은 보류했습니다. 현재 대사는 자막입니다.
Audio/dialogue_manifest.json에 대사와 오디오 파일 슬롯을 보관했습니다.
EurydiceDirector의 Lines에서 각 항목의 Clip에 나중에 WAV/MP3를 넣으면 재생됩니다.
에우리디케 대사는 캐릭터 위치의 공간 오디오, 하데스는 안내용 2D 오디오입니다.
lyre_cue.wav는 테스트용으로 합성한 짧은 리라 유사 효과음입니다.

제한
이것은 v1 동굴을 이용한 시나리오 동작 테스트입니다. VR 헤드셋의 실제 양안 렌더링,
손 추적·컨트롤러 입력과 기기 성능은 별도 확인이 필요합니다.
실제 체험 3분 고정 재생이 아니며, 자막 길이와 사용자 이동/선택에 따라 시간이 달라집니다.
자동 검사 결과는 Documentation/scenario_test_results.json에서 확인합니다.
