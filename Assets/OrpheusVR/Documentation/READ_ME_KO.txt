설치 및 실행
현재 RollBall 프로젝트에 씬이 생성되어 있습니다.
Assets/OrpheusVR/Scenes/Orpheus_Underworld.unity
Unity 6000.3.26f1 / Universal Render Pipeline 17.3.0
다른 프로젝트에서는 OrpheusVR_CaveMap_v1.unitypackage를 가져오세요.
필요 패키지: Universal RP, Input System, AI Navigation (현재 프로젝트에 설치됨).

조작
Play 실행 후 WASD 이동, 마우스 오른쪽 버튼을 누르고 시점 회전.
Enter: 하데스 방에서 귀환 통로 시작점으로 이동.
E: 근처 리라 / 공명 바위 / 모래시계 / 길 선택과 상호작용.
F: 자동 동선 투어. H: 영문 디버그 안내 표시 전환.
XR 입력이 활성화된 환경에서는 헤드 위치/회전, 왼손 스틱 이동,
오른손 스틱 30도 회전, 오른손 기본 버튼 상호작용을 읽습니다.
현재 프로젝트에는 활성 XR 로더가 없어 헤드셋 실행은 미검증입니다.
대상 기기에 맞는 XR 로더, Android 빌드, 추적 원점 설정은 별도 필요합니다.

공간 구성 (Unity 단위 1 = 1m)
S1 하데스 방: 중심 (0,0,-2), 넓은 만남 공간과 대화/손잡기 앵커.
S2-1 리라 통로: (0,0,10) → (15,1.2,30) → (18,2.6,47).
리라: 주 동선 옆 x13.5 / z30.
S2-2 갈림길: x18 / z47. 오답: x9/z52 → x5/z58의 막다른 길.
정답: x24/z52 → x29/z59. 초기 길 안내는 끄고, 오답 진입 후 대체 길 표시.
S2-3 침수 회랑: x29 / z59~78, 수면 상승/배수 미리보기, 공명 바위와 길돌.
S3 선택의 문턱: x25 / z87~96, 기다림의 모래시계와 빛나는 길.
지상: x25 / z100 이후, 잔디 바닥과 Kenney 참나무.

현재 구현 범위
연속된 동굴 메시, 바닥/벽/천장 충돌체, 바위 배치, 바닥 유도등,
리라/공명 바위/모래시계의 단순 대체 모델, 침수/배수 미리보기,
경로 앵커, 데스크톱 이동, XR 입력 훅, NavMesh 경로.
70도 경고 / 120도 2초 뒤돌아보기의 디버그 판정도 포함합니다.
하데스 얼굴과 에우리디케는 완성 캐릭터가 아닌 연결용 앵커/대체물입니다.
음성, 정령 연출, 손 추적/잡기, 완성된 분기 엔딩, 체험 시간 기록은 포함하지 않습니다.
맵 동선을 검토하는 프로토타입이며, 전체 3분 시나리오를 강제 진행하지 않습니다.
F 자동 투어는 체험 동선을 보는 개발용 기능이며 모든 상호작용을 수행하지 않습니다.
VR 프레임레이트와 멀미/가독성은 대상 헤드셋에서 별도 검증해야 합니다.
