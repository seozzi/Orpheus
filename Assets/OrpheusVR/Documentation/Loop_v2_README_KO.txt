VR 동굴 맵 — 원형 동선 v2

새 씬
Assets/OrpheusVR/Scenes/Orpheus_Underworld_Loop_v2.unity
기존 Orpheus_Underworld 씬은 별도로 유지됩니다.

변경 내용
길게 뻗던 동선을 반경 약 18m의 큰 호로 감았습니다.
본선은 약 285도를 돌아온 뒤, 완만한 곡선으로 바깥쪽 지상 출구로 이어집니다.
시작의 하데스 방과 귀환 출구가 같은 쪽에 모이도록 배치했습니다.
막다른 갈림길은 고리 안쪽으로 향합니다. 갈림길 입구의 바위는 비웠습니다.
리라, 침수, 공명 바위, 모래시계, 유도등, 캐릭터 연결 앵커도 함께 재배치했습니다.
수면은 곡선을 따르는 메시로 바꿨고 지상 잔디 공간은 24×24m로 줄였습니다.
이벤트 진행은 직선 Z좌표 대신 경로상의 위치를 기준으로 판정합니다.

에디터 조작
Play → Enter: 하데스 방에서 귀환 시작점으로 이동.
WASD 이동 / 우클릭을 누르고 시점 회전 / E 상호작용.
F: 자동 동선 투어 / H: 디버그 안내 숨김.

검증
본선의 촘촘한 경로점 67개와 막다른 길 1곳, 총 68개 NavMesh 경로 연결 확인.
동굴 충돌체와 NavMesh를 새 곡선 형상에서 재생성했습니다.
이 결과는 가상 맵 재배치입니다. 실제 전시장 크기는 아직 미정입니다.
실공간 1:1 보행, 리디렉티드 워킹, 가디언 경계 대응, 헤드셋 성능은 별도 검증 대상입니다.
기존 v1과 마찬가지로 완성 캐릭터·음성·손잡기와 전체 엔딩 연출은 포함하지 않습니다.
