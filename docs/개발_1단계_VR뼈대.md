# 1단계: VR 뼈대 (2026-11-24)

v1 동굴 맵 위에 3분 체험의 흐름 전체를 자막·임시 형상으로 먼저 돌아가게 만든 단계.
음성, 2D 홀로그램, 소리, 물 셰이더는 다음 단계에서 같은 자리에 끼운다.

## 들어간 것
- 헤드셋 리그: OVRCameraRig + CharacterController (동굴 경사 따라 이동, 벽 충돌)
- 조작: 왼손 스틱 이동(뒤로 당기면 뒷걸음질), 오른손 스틱 30° 스냅 회전, A 또는 오른손 트리거 상호작용, 손을 대상에 가까이 대면 닿음 판정
- S1: 하데스 대사 → 뒤돌아보기 연습(경고만) → 에우리디케 등장 → 손잡기 → 페이드 후 통로 시작점으로 이동
- 뒤돌아보기 판정: 통로 정면 기준 70° 경고(자막 + 진동, 뒤로 갈수록 강하게) / 120° 2초 → 에우리디케 상실 / 막다른 길 안에서는 막다른 끝이 정면
- S2-1 리라 연주, S2-2 막다른 길 → 대체 길 점등, S2-3 넘어짐·침수·안개 → 5초 뒤 공명 바위 → 물 빠짐, 돌 솟음
- S3 선택: 모래시계(기다림, 4초) / 빛나는 길(홀로). 상실 상태면 선택 없이 홀로
- 엔딩: 궤적 기록(정지 지점·머문 시간·경고 중 정지 = '망설임', 구간별 시간) → 통로 위 빛의 선 + 출구 위 축소 지도

## Unity에서 할 일 (Mac)
1. Unity로 `~/Orpheus`를 열고 컴파일이 끝나길 기다림 (콘솔 에러 확인)
2. 메뉴 `Tools > Orpheus VR > Setup VR Experience` 실행 → `Orpheus_VR_Main` 씬 생성
3. Play → 데스크톱 미리보기: WASD 이동, 우클릭 드래그 시점, E 상호작용, Enter 손잡기 건너뛰기
4. 헤드셋용: `Meta > Tools > Project Setup Tool` → Android 탭 Fix All (OpenXR 로더 설치), `File > Build Profiles > Meta Quest` → Build And Run

## Claude Code(MCP)에 줄 프롬프트
```
1단계 VR 뼈대 검증을 진행해 줘. 코드는 고치지 말고 먼저 확인만.
1. refresh_unity 후 read_console 에러/경고 수와 첫 에러 3개
2. Tools > Orpheus VR > Setup VR Experience 메뉴 실행 (execute_menu_item)
3. Orpheus_VR_Main 씬의 "Orpheus Player (VR)", "ORPHEUS - VR Experience" 존재와
   OrpheusFlow 인스펙터 참조 중 비어 있는 것
4. Play 모드 10초 실행 후 콘솔 에러 재확인, 정지
결과를 항목, 상태, 조치 표로 보고해 줘.
```
에러가 있으면: `콘솔 첫 에러의 원인을 설명하고 해당 스크립트만 고쳐 줘. 고친 뒤 위 1~4를 다시 해 줘.`

## 헤드셋 착용 확인 체크리스트
- [ ] 하데스(구) 정면에서 시작, 눈높이 자연스러움
- [ ] 고개를 70° 넘게 돌리면 "돌아보지 마라" + 진동, 뒤로 갈수록 강해짐
- [ ] 에우리디케 손(작은 빛 구슬)에 손을 대면 진동 후 통로로 이동
- [ ] 통로에서 120° 넘게 2초 → 상실 연출, 이후 홀로 진행
- [ ] 막다른 길에서 스틱 뒤로 당겨 뒷걸음질 → 경고 없이 빠져나옴
- [ ] 물이 차오르고 5초 뒤 바위에 손 → 물 빠짐
- [ ] 모래시계/빛나는 길 선택, 출구에서 궤적과 축소 지도
- [ ] 자막 한글이 깨지지 않음, 양쪽 눈에 모두 보임
- [ ] 끊김·멀미 없음 (72fps)

## 조정 값 (인스펙터)
| 컴포넌트 | 값 | 기본 |
|---|---|---|
| LookBackJudge | warnAngle / lossAngle / holdSeconds | 70 / 120 / 2 |
| OrpheusPlayer | moveSpeed / snapAngle(0이면 스냅 끔) | 1.3 / 30 |
| OrpheusRoute | forkStart / floodStart / choiceStart / exitStart | 43 / 58 / 84 / 101 |
| OrpheusFlow | floodRise / resonanceDelay / waitSeconds | 1.8 / 5 / 4 |

## 알려진 한계 (다음 단계)
- 대사는 자막만. TTS 음성, 경고음, 발소리(뒤따라오는 에우리디케 3D 사운드)는 2단계
- 에우리디케·하데스는 임시 형상(캡슐, 기존 구). 2D 홀로그램 PNG + 디졸브 셰이더는 3단계
- 정령, 리라 집어 들고 줄 튕기기, 폭포 파티클, 물 셰이더는 4단계
- 자막 폰트는 OS 한글 폰트를 씀. Quest에서 글자가 안 보이면 TextMeshPro 한글 폰트 에셋으로 교체
- S3에서 하데스가 말하는 세 번째 선택지(뒤돌아보고 머물기)의 결말은 기획 확정 필요. 지금은 뒤돌아보면 일반 상실과 같음
