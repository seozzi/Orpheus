Orpheus VR — v1 프로젝트 전달본

이 ZIP은 Unity 편집 프로젝트입니다. 더블클릭으로 실행하는 EXE / APP이 아닙니다.
현재 기본 동선은 v1이며, 원형 v2 씬도 비교용으로 함께 보관했습니다.

다른 컴퓨터에서 여는 방법
1. ZIP 파일을 로컬 폴더에 완전히 압축 해제합니다.
2. Unity Hub와 Unity Editor 6000.3.26f1을 설치합니다.
3. Unity Hub에서 Add / Add project from disk로 OrpheusVR_v1_Project 폴더를 선택합니다.
   Assets, Packages, ProjectSettings 세 폴더가 바로 보이는 위치입니다.
4. Open으로 프로젝트를 엽니다. 첫 실행에는 인터넷 연결이 필요합니다.
   패키지 다운로드와 에셋 재임포트가 끝날 때까지 기다립니다.
5. 첫 임포트 후 v1 씬이 자동으로 열리도록 전달본에 1회 초기화 스크립트를 추가했습니다.
   자동으로 열리지 않으면 다음 씬을 직접 더블클릭합니다.
   Assets/OrpheusVR/Scenes/Orpheus_Underworld.unity
6. 상단 Play 버튼을 누릅니다. Game 탭이 보이지 않으면 Window > General > Game을 엽니다.
7. Game 화면을 클릭하고 Enter로 여정을 시작하거나 F로 자동 투어를 실행합니다.

조작
WASD: 이동
마우스 오른쪽 버튼을 누른 채 움직이기: 시점 회전
E: 가까운 소품 상호작용
F: 자동 투어 켜기 / 끄기
H: 화면 안내 켜기 / 끄기
종료: Unity 상단 Play 버튼을 다시 누릅니다.

전달본 구성
Assets: 씬, 메시, 텍스처, 소품, 코드와 CC0 에셋 라이선스.
Packages: 패키지 목록과 버전 잠금 파일.
ProjectSettings: 렌더링, 입력 등 프로젝트 설정. 전달본의 빌드 씬 목록은 v1입니다.
Library / Temp / Logs / UserSettings는 전달하지 않으며 새 컴퓨터에서 재생성됩니다.
개발용 Unity MCP 연결 패키지와 해당 설정 에셋은 전달본에서 제외했습니다.
원본 RollBall 프로젝트의 패키지 설정은 변경하지 않았습니다.

실행 범위
Windows 또는 macOS에서 해당 Unity Editor로 여는 프로젝트 전달본입니다.
다른 컴퓨터에서 실제 임포트/실행한 결과는 아직 확인하지 않았습니다.
VR 헤드셋 실행용 XR 로더 및 기기별 빌드 설정은 별도로 필요합니다.
현재 제공하는 것은 PC에서 동굴 맵을 확인하는 프로토타입입니다.
